# PaceMaker: A Practical Tool for Pacing Video Games \[@geheebPaceMakerPracticalTool2024]

*   focus: pacing (part of player experience)
*   automatic calculation of experience parameters based on artifact?

## General

### Pacing

> Pacing describes the rhythm that results from the recurring patterns of rhythmic parameters in time.

*   **artifact parameters**: tangible values and properties of the game itself

*   **experience parameters**: experience of player while interacting with game

    *   intensity, also: engagement, threat, movement impetus, tempo
    *   example: calculation of intensity $f_i$ based on number of jumps, enemies, tiles, etc

### Experience Chart

*   **beats** = nodes, represent part of game

    *   properties: name, description, … -> expandable!

*   edges represent dependencies

*   **pacing diagrams** visualize data along **selected path**
